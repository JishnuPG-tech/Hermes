# OpenCode Serve (TorProxy Space) 🚀

Self-hosted AI developer backend and ACP (Agent Client Protocol) server powering the **MyHermes Android OS** and **OpenCode / Zed / VS Code** integrations.

Hosted on **Hugging Face Spaces** on port `7860`.

---

## 🌟 Key Endpoints

- **Base URL**: `https://jishnupg-torproxy.hf.space`
- **Health**: `GET https://jishnupg-torproxy.hf.space/health`
- **Chat Completions**: `POST https://jishnupg-torproxy.hf.space/v1/chat/completions`
- **Models**: `GET https://jishnupg-torproxy.hf.space/v1/models`
- **Remote Config**: `GET / POST https://jishnupg-torproxy.hf.space/v1/config`
